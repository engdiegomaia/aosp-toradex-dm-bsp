# Ixora carrier configuration

Reserve this directory for settings that are specific to Apalis iMX8QM on Ixora. The POC reports Ixora V1.2 and documents HDMI/LVDS, USB touch, Ethernet, and boot observations. Device-tree changes must be checked against the exact NXP Android kernel baseline and matching Toradex BSP before being added here.

No carrier-specific source has been imported yet. Record the source file/revision, connector or circuit dependency, validation evidence, and license for each future adaptation.
