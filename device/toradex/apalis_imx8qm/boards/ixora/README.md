# Ixora carrier notes

The current build target is specifically Apalis iMX8QM + Ixora V1.2. Its NXP product still combines module and carrier configuration because the NXP build expects a single `apalis_imx8qm` product path. Keep new Ixora-only settings here when they can be composed safely without changing NXP product discovery.

Reference observations are from Apalis PN 0037, HW V1.1B, Ixora V1.2. Record the source revision, connector dependency, and dated hardware evidence for each carrier adaptation. Do not treat Ixora settings as common to other Apalis carrier boards.
