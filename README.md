# Toradex Community AOSP BSP

A community-maintained integration of SoC-vendor Android BSPs with Toradex module and carrier-board support. This project is not an official Toradex Android BSP and is not maintained or officially supported by Toradex.

The initial reference is **Apalis iMX8QM + Ixora**, based on NXP Android `android-16.0.0_1.2.0`. The first pinned source manifest and its known limitations are recorded in [`manifests/android16/nxp-imx8qm-poc-2026-09-15.xml`](manifests/android16/nxp-imx8qm-poc-2026-09-15.xml) and [`docs/vendor-baselines.md`](docs/vendor-baselines.md). It is an inventory snapshot, not yet a clean-build release manifest.
